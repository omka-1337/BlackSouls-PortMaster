Game Information
Title: BLACK SOULS
URL: https://store.steampowered.com/app/1424910/BLACK_SOULS/
Port: https://github.com/omka-1337/BlackSouls-PortMaster

Instructions:
Not ready to run, and the game is adult content. It is a paid title, so this ships
the engine only and you need your own copy. Copy Audio/, Graphics/, Fonts/,
Game.ini and Game.rgss3a into the blacksouls folder. Keep both Game.rgss3a and the
loose Graphics folder: nine assets exist in both and the loose copies win.

Engine is mkxp-z (VX Ace / RGSS3), GLES, no gl4es. Input is native
SDL_GameController, so nothing is remapped and the .ini is deliberately blank;
gptokeyb2 only provides Start+Select. Renders at 640x480.

Tested on my RG40XX H (Knulli, H700 / Mali-G31, 1GB): boots, plays, battles and
saves work, peak RSS around 233 MB. Only device I own, so every other CFW is open.

Knulli oddity, likely not the port: a few seconds after exit the firmware draws its
own save progress screen. Relaunching inside that window makes both draw at once
and the picture tears. Waiting it out clears it.

| Button | Action |
|--|--|

Face buttons are Nintendo-style here, so Confirm is on B. Report if yours differs.
